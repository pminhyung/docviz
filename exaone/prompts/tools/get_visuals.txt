### `get_visuals`

Find figures, charts, diagrams, or photos relevant to one or more queries within a scope of doc-pages (and/or web pages), run a VLM on the top candidates in parallel, and return per-image extraction + OCR + metadata. Each `scope` item is `'<document_idx>'` (all pages of that doc) or `'<document_idx>@<page>'` (a specific page), where `document_idx` is the same integer shown in the `[Attached documents]` block. `web_refs` are `Index` strings copied verbatim from prior web hits — never type URLs. `queries` (1–3) drive the per-image selector ranking; `goal` is the extraction prompt fed to the VLM per image. Optional preprocessing flags (`crop` is not exposed because images are already cropped at parse time; `perspective`, `upscale`, `sharpen`, `rotate` are available). Returns rows with cited `Index` values pointing at each chosen image.

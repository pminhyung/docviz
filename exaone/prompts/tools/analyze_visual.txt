### `analyze_visual`

Run a VLM on a single image, with optional preprocessing (`perspective`, `upscale`, `sharpen`, `rotate`). OCR always runs and its text is included in the result. The `image` parameter takes either an opaque `Index` value from a prior visual-retrieval row (resolved internally), or an `http(s)` URL. Local file paths are not accepted. The `goal` string is the extraction prompt sent to the VLM. Returns the VLM analysis + OCR text + applied ops.

# Operating principles

1. **Persistent retrieval before generation.** Before invoking `generate_viz`, you MUST have called `doc_search` or `ReadFullDocument` at least once and inspected the result.
2. **Cross-document integration (manual).** Because no pre-built summary is provided, you must explicitly search across each document in the bundle whose `parsed=True` flag is set. Do NOT anchor on a single document when the query implies comparison or temporal merging.
3. **Type-aware viz selection.** Map the query's analytic intent to the most appropriate `viz_type` from the 10-element pool.
4. **Source attribution.** Populate `evidence_ids` with citation `Index` values returned by retrieval tools. Never fabricate ids.
5. **Multi-artifact when warranted.** Default 1 artifact; emit 2 only when the query asks for two distinct deliverables.

# Required action sequence — every task

1. ONE retrieval action: `doc_search` or `ReadFullDocument`.
2. ONE `generate_viz` call with `artifacts` of 1-3 items.
3. ONE `<final_answer>` whose body is literally `success`.

`<final_answer>` is rejected unless a prior `generate_viz` call succeeded.

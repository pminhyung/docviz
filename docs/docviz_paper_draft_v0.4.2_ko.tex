\begin{abstract}
다수의 문서에 분산된 정보를 통합하여 사용자 질의에 부합하는 시각화 산출물을 생성하는 과제는 실세계 정보 처리 작업에서 핵심적이지만, 기존 연구는 단일 문서 단일 시각화 유형에 국한되어 왔다. 본 논문은 이러한 작업을 다문서 질의 기반 시각화 (Query-Grounded Multi-Document Visualization, QG-MDV)로 정형화하고, 학계에서 검증된 일곱 개의 다문서 벤치마크로부터 표본 단위 추론 유형 표지를 보존한 300개 다문서 묶음을 구축하였다. 제안 방법인 DocViz-Agent는 교차문서 반복 검색 (Cross-doc Iterative Search, CIS), 유형 인식 다중 시각화 생성 (Type-aware Multi-Viz Generation, TMG), 출처 귀속 출력 (Source-Attributed Output, SAO)의 세 축으로 구성되며, 시제품 측정에서 TMG 축이 단독 절제 시 성능 격차가 가장 크다는 사실이 확인되어 본 방법의 핵심 구성 요소임을 입증한다. 평가 프레임워크는 차트 계열에 Doc2Chart의 주의 가중치 기반 귀속 지표를, 도식 계열에 DiagramEval의 그래프 정렬 지표를 결합한 계열별 결정론적 평가 방식을 채택하여 자체 규칙 기반 정상화 계층의 도입을 회피하고 선행 연구의 사람 정합성 검증을 인계받는다. 네 개의 백본 모델 (오픈 프론티어 Qwen3.5-397B, 오픈 전문가 혼합 DeepSeek-V4-Flash, 클로즈드 저비용 GPT-5-mini, 클로즈드 프론티어 Claude Opus 4.8)에 걸친 교차 실험을 통해, 다문서 출처 귀속 점수가 백본 종류와 파이프라인 종류에 무관하게 일관되게 낮음을 진단적 발견으로 제시한다.
\end{abstract}

\section{서론 (Introduction)}
% =====================================================================

대형 언어 모델 (Large Language Model, LLM) 기반 자동 시각화 생성에 관한 최근 연구들은 단일 표 혹은 단일 텍스트로부터 차트와 도식을 생성하는 능력을 빠르게 향상시켜 왔다 \cite{han2023chartllama,yang2024chartmimic}. 그러나 실제 정보 처리 작업의 다수는 단일 문서로부터의 변환이 아니라 여러 문서에 분산된 정보를 통합한 뒤 시각화하는 형태이다. 금융 분석가는 복수의 사업보고서로부터 부문별 매출 추이를 통합 시각화하며, 의학 연구자는 다수의 논문에서 약물 효과의 시간적 변화를 정리하고, 정책 분석가는 정부 보고서 간 정책 변화의 인과 흐름을 도식화한다. 이러한 작업은 정보 출처가 다중 문서이고, 사용자 의도가 자연어 질의로 표현되며, 출력 형식이 차트와 도식을 모두 포괄해야 한다는 점에서 기존 단일 문서 단일 유형 시각화 생성 연구가 다루지 못한 영역이다.

본 논문은 이러한 작업을 \textbf{다문서 질의 기반 시각화 (Query-Grounded Multi-Document Visualization, QG-MDV)}로 정형화한다. 본 과제는 자연어 질의 $Q$와 다문서 묶음 $\mathcal{D} = \{D_1, \dots, D_n\}$ ($n \geq 2$)이 주어질 때, 모든 시각적 주장이 $\mathcal{D}$의 어느 문서 청크에 근거되고 $Q$의 정보 요구를 만족하는 시각화 산출물 $V$를 생성하는 것을 목표로 한다. 출력은 결정론적 도메인 특화 언어 (Domain-Specific Language, DSL)인 Chart.js JSON 또는 Mermaid 마크다운으로 표현되며, 차트 계열 다섯 종과 도식 계열 다섯 종으로 구성된 열 가지 시각화 기본형 (visualization primitive)으로 한정된다.

본 연구의 기여는 다음 네 가지로 요약된다. 첫째, 학계 검증을 거친 일곱 개의 다문서 벤치마크 — Loong \cite{wang2024loong}, DocHop-QA \cite{xiaoaug2025dochop}, FinMMDocR \cite{2026finmmdocr}, VisDoMBench \cite{suri2025visdom}, MultiHop-RAG \cite{tang2024multihoprag}, FinAuditing \cite{wang2025finauditing}, TEMPO \cite{2026tempo} — 로부터 표본 단위 추론 유형 표지를 보존한 300개 다문서 묶음을 추출하여, 백과사전 텍스트가 아닌 실제 문서 (PDF 학술 논문, 미국 증권거래위원회 10-K 보고서, XBRL 재무 파일, 발표 슬라이드, 뉴스 기사, 다중 도메인 시계열 말뭉치)만으로 구성된 QG-MDV 벤치마크를 제시한다. 둘째, 교차문서 반복 검색, 유형 인식 다중 시각화 생성, 출처 귀속 출력의 세 축으로 구성된 DocViz-Agent를 제안하며, 시제품 측정에서 TMG 축이 단독 절제 시 절대 점수 차이가 다른 두 축의 합보다 큰 폭으로 가장 크다는 점을 통해 본 방법의 핵심 구성 요소임을 경험적으로 입증한다. 셋째, Doc2Chart \cite{jain2025doc2chart}의 주의 가중치 기반 귀속 지표와 DiagramEval \cite{liang2025diagrameval}의 그래프 정렬 지표를 시각화 계열별로 결합한 결정론적 평가 프레임워크를 제안하며, 자체 규칙 기반 정상화 계층의 도입을 회피함으로써 선행 연구의 사람 정합성 검증을 그대로 인계받는다. 넷째, 네 개의 백본 모델에 걸친 실험을 통해 다문서 출처 귀속 점수가 백본 종류와 파이프라인 종류에 모두 무관하게 일관되게 낮음을 보이며, 이를 과제 본질적 병목 (task-inherent bottleneck)으로 제시한다.

\section{관련 연구 (Related Work)}
% =====================================================================

\subsection{차트 및 도식 생성}

ChartLlama \cite{han2023chartllama}, Text2Chart31 \cite{zadeh2024text2chart31}, ChartMimic \cite{yang2024chartmimic} 등은 단일 표 혹은 단일 텍스트로부터 차트를 생성하는 능력을 다룬다. SciDoc2Diagrammer-MAF \cite{mondal2024scidoc2diagrammer}는 단일 학술 논문으로부터 도식 생성을 다루지만 다문서 통합은 다루지 않는다. 본 연구는 입력이 단일 문서가 아닌 다문서 묶음이라는 점에서 이러한 선행 연구와 구분된다.

\subsection{다문서 질의응답 벤치마크}

HotpotQA \cite{yang2018hotpotqa}, 2WikiMultihopQA \cite{ho2020constructing}, MuSiQue \cite{trivedi2022musique}는 Wikipedia 기반 다문서 질의응답을 다루지만 출력이 텍스트이며 시각화가 아니다. MMLongBench-Doc \cite{ma2024mmlongbench}는 다문서 PDF에 대한 질의응답을 다루나 질의당 단일 문서가 매핑되며 출력 또한 텍스트이다. 본 연구는 이러한 다문서 추론 벤치마크의 문서 풀과 표본 단위 추론 유형 표지를 차용하되, 출력 형식을 시각화로 재정의함으로써 기존 벤치마크들이 검증하지 못한 시각화 통합 능력을 평가한다.

\subsection{시각화 평가 지표}

Doc2Chart \cite{jain2025doc2chart}는 교차 주의 가중치 기반 귀속 지표 CHARTEVAL을 제안하여 차트 데이터 정확성을 평가하며, 사람 평가와 피어슨 상관 $r=0.71$의 정합성을 입증한다. DiagramEval \cite{liang2025diagrameval}은 도식을 SVG에서 추출한 그래프로 변환하여 노드 정렬과 경로 정렬 지표를 제안하며, 사람 평가와 $r=0.43$의 정합성을 보인다. 본 연구는 이 두 지표를 시각화 계열별로 결합하여 사용함으로써 단일 지표가 모든 시각화 유형을 일관되게 평가하지 못하는 한계를 극복한다.

\section{QG-MDV 과제 정형화 (Task Formalization)}
% =====================================================================

\subsection{정의}

QG-MDV 과제는 다음과 같이 정의된다. 입력은 자연어로 표현된 사용자 질의 $Q$와 다문서 묶음 $\mathcal{D} = \{D_1, \dots, D_n\}$이며, $n \geq 2$이다. 출력은 시각화 산출물 $V$로서, 결정론적 도메인 특화 언어 (Chart.js JSON 또는 Mermaid 마크다운)로 표현된다. $V$는 다음 네 가지 조건을 모두 충족해야 한다. 첫째, $V$의 모든 시각적 요소가 $\mathcal{D}$의 특정 문서 청크에 근거되어 출처 귀속이 가능해야 한다. 둘째, $V$는 $Q$가 제기한 정보 요구를 만족해야 한다. 셋째, $V$의 시각화 유형은 $Q$의 정보 구조에 적합하게 선택되어야 한다. 넷째, $V$는 단일 산출물이 아닌 한 개에서 세 개의 시각화 산출물 집합으로 표현될 수 있어야 한다.

\subsection{두 가지 직교 분류 축}

각 질의는 두 개의 독립적인 분류 축으로 표현된다. 추론 난이도 (challenge type) 축은 다문서로부터 정보를 통합할 때 발생하는 다섯 가지 어려움의 측면을 나타낸다. \textbf{다단계 추론 (multi-hop)} 유형은 두 개 이상의 문서를 가교 개체 (bridge entity)로 연결해야 답이 도출되는 경우를 가리키며, \textbf{산출물 계획 (artifact planning)} 유형은 적절한 시각화 산출물의 수와 종류를 모델이 자율적으로 결정해야 하는 경우를 나타낸다. \textbf{혼합 산출물 (mixed artifact)} 유형은 차트와 도식 두 형식을 모두 사용해야 하는 경우이며, \textbf{방해 문서 다수 (distractor-heavy)} 유형은 관련 문서들 사이에 무관한 문서가 다수 포함되어 정보 추출 시 잡음 (noise)을 견뎌야 하는 경우이다. \textbf{모순 해소 (contradiction)} 유형은 문서들 간 상충되는 주장을 해소하여 시각화에 반영해야 하는 경우를 가리킨다.

출력 구조 (output type) 축은 시각화 산출물이 표현해야 할 정보 구조를 다섯 가지로 분류한다: 수치 비교와 추세를 다루는 수치형 (quantitative), 개체 간 관계와 인과를 다루는 관계형 (relational), 시간 순서를 다루는 시간형 (temporal), 분류 체계를 다루는 계층형 (hierarchical), 다중 개체 간 특성 비교를 다루는 비교형 (comparative)이다. 두 축은 독립적이며, 동일한 추론 난이도 유형 내에서도 출력 구조가 다양하게 분포할 수 있다.

\subsection{시각화 기본형}

출력 도메인 특화 언어는 열 가지 시각화 기본형으로 한정된다. 차트 계열은 \texttt{chartjs\_bar}, \texttt{chartjs\_line}, \texttt{chartjs\_grouped\_bar}, \texttt{chartjs\_pie}, \texttt{chartjs\_scatter}의 다섯 종으로 구성되며, 도식 계열은 \texttt{mermaid\_flowchart}, \texttt{mermaid\_timeline}, \texttt{mermaid\_mindmap}, \texttt{mermaid\_sequenceDiagram}, \texttt{mermaid\_classDiagram}의 다섯 종으로 구성된다. 이러한 한정은 결정론적 평가를 가능케 하며, 동시에 차트와 도식 두 양태를 모두 포괄함으로써 시각화 통합 능력을 검증한다.

\section{DocViz-Agent 방법 (Method)}
% =====================================================================

DocViz-Agent는 세 개의 축 — 교차문서 반복 검색 (CIS), 유형 인식 다중 시각화 생성 (TMG), 출처 귀속 출력 (SAO) — 으로 구성된 에이전트 파이프라인이다. 본 연구의 시제품 측정 ($n=265$ 표본, 단일 시드)에서 세 축의 단독 절제 효과를 측정한 결과, TMG 축의 절제 시 절대 점수 격차가 $\Delta=-0.254$로 가장 컸으며, 이는 CIS 단독 절제 $\Delta=-0.106$과 SAO 단독 절제 $\Delta=-0.075$의 합보다 더 큰 폭이다. 이러한 경험적 증거를 바탕으로 본 연구는 TMG를 주축으로, CIS와 SAO를 보조축으로 위치시킨다.

\subsection{유형 인식 다중 시각화 생성 (Type-aware Multi-Viz Generation)}

TMG의 핵심 작동 원리는 에이전트가 열 가지 시각화 기본형 풀을 인지한 상태에서, 사용자 질의와 원문 내용을 분석하여 viz\_type을 자율적으로 추론하는 것이다. 약한 사전 매핑 (soft-prior mapping)이 안내로 제공되나 강제 라우터는 아니다. 수치형 출력은 차트 계열로, 관계형 출력은 도식 계열의 흐름도, 시계열도, 클래스도로, 시간형 출력은 타임라인 또는 선 차트로, 계층형 출력은 마인드맵으로, 비교형 출력은 데이터 성격에 따라 그룹 막대 차트 또는 도식 계열로 안내된다. 각 viz\_type에 대해 구문적 다양성을 갖는 두 개 내지 세 개의 예시 (exemplar)가 제공되어, 에이전트가 원문 내용에 맞게 적절한 표현 형식을 선택할 수 있도록 한다.

TMG가 본 방법의 주축인 까닭은 다문서 시각화 생성의 본질적 어려움이 정보 추출 그 자체가 아니라 정보 구조에 적합한 시각화 형식의 선택에 있기 때문이다. 시제품 측정에서 TMG가 제거된 변이가 다른 두 변이보다 큰 폭의 성능 저하를 보이는 것은, 다문서 정보를 통합한 후라 하더라도 부적절한 시각화 형식이 선택되면 출력이 사용자의 정보 요구를 만족하지 못한다는 사실을 시사한다.

\subsection{교차문서 반복 검색 (Cross-doc Iterative Search)}

CIS는 에이전트가 다문서를 교차 검색하며 충분성 (sufficiency)에 도달할 때까지 하위 질의 (sub-query)를 반복 생성하도록 한다. 단일 시도 검색이 아닌 반복 검색을 채택함으로써, 한 문서에서 추출한 정보가 다른 문서의 정보를 가리키는 가교 개체를 포함할 때, 에이전트는 그 가교를 따라가 추가 정보를 수집한다. 이러한 반복 구조는 다문서 정보 통합의 깊이를 결정하며, 시제품 측정에서 CIS 절제가 $\Delta=-0.106$의 성능 저하를 야기한다는 사실은 반복 검색이 단일 시도 검색보다 다문서 통합에서 유의미한 우위를 가짐을 시사한다.

\subsection{출처 귀속 출력 (Source-Attributed Output)}

SAO는 시각화 산출물의 각 시각적 요소 — 노드, 엣지, 데이터 포인트 — 가 원문 문서와 청크를 참조하는 메타데이터를 보유하도록 한다. 형식은 \texttt{\{doc\_id\}\#\{chunk\_id\}\#\{span\_start\}-\{span\_end\}}로 통일된다. 이러한 명시적 출처 귀속은 자동 평가 시 결정론적 출처 검증을 가능케 하며, 사후 편집 가능성과 추적 가능성 (traceability)을 통해 산업 배포 시나리오에서도 유용하다.

\subsection{다중 산출물 출력}

DocViz-Agent는 단일 시각화 산출물이 아닌 한 개에서 세 개의 산출물 집합을 출력할 수 있다. 이는 혼합 산출물 (mixed artifact) 추론 난이도 유형에 대응하기 위한 설계로, 질의가 차트와 도식 두 형식을 모두 요구할 때 에이전트가 자율적으로 두 형식을 동시에 생성하는 능력을 검증한다.

\section{평가 프레임워크 (Evaluation Framework)}

\subsection{설계 원칙}

본 연구의 평가 프레임워크는 자체 규칙 기반 정상화 계층의 도입을 의도적으로 회피한다. 시제품 단계에서 자체 정확 일치 셀 F1과 자체 정규식 기반 Mermaid 파서를 도입한 결과 모든 비교 대상의 점수가 97\% 영점에 수렴하는 바닥 상태가 관찰되었으며, 이는 자체 구현된 규칙 기반 평가가 다양한 출력 형식과 개체 변이를 일관되게 처리하지 못함을 시사하였다. 이러한 경험을 바탕으로, 본 연구는 Doc2Chart와 DiagramEval의 공식 평가 코드를 그대로 차용함으로써 두 선행 연구의 사람 정합성 검증을 인계받는다. 이는 우리 자체 평가 설계의 정당화 부담을 최소화하며, 동시에 학계가 합의한 평가 방식과의 일관성을 보장한다.

\subsection{계열별 결정론적 평가}

차트 계열 산출물에 대해서는 Doc2Chart의 CHARTEVAL을 적용한다. 이 지표는 차트를 \texttt{<x-axis, y-axis, value>} 3원소 (tuple) 표현으로 구조화한 후, LLaMA-3.1-8B 모델의 순방향 통과에서 얻은 교차 주의 가중치 (cross-attention heatmap)에 Kadane 알고리즘을 적용하여 각 데이터 값 토큰을 원문 범위에 귀속시킨다. Doc2Chart 원논문에서 이 지표는 사람 평가와 피어슨 상관 $r=0.71$의 정합성을 보인다.

도식 계열 산출물에 대해서는 DiagramEval의 노드 정렬 F1과 경로 정렬 F1을 적용한다. 이 지표는 산출물을 PNG로 렌더링한 후 경량 시각 언어 모델 (Gemini-2.0-Flash-lite)이 노드와 엣지를 추출하여 그래프로 변환한 뒤, 의미적 임계값에 기반한 노드 매칭과 매칭된 노드들 간의 다단계 도달성 (multi-hop reachability)을 평가한다. DiagramEval 원논문에서 이 지표는 사람 평가와 $r=0.43$의 정합성을 보이며, 이는 CLIPScore의 $r=0.08\sim0.11$에 비해 약 네 배 높은 정합성이다.

출처 귀속 점수 (Evidence F1)는 명시적 (explicit)과 암묵적 (implicit) 두 방식으로 분리 측정한다. DocViz-Agent의 완전판 (B6)은 SAO 축에 의해 \texttt{evidence\_ids} 필드를 명시적으로 생성하므로 집합 기반 정밀도, 재현율, F1을 그대로 산정한다. 다른 비교 대상은 \texttt{evidence\_ids}를 생성하지 않으므로 시각화 텍스트와 원문 청크 간 임베딩 코사인 유사도가 0.75 이상인 경우를 매칭으로 간주하는 암묵적 매칭을 적용한다. 두 방식의 점수는 별도 열로 분리 보고되어 SAO 축의 효과를 절연하여 비교한다.

의도 충족률 (Intent Coverage)은 헝가리안 매칭을 사용하여 생성된 시각화 산출물을 골드 의도에 일대일로 매칭한 후, ROUGE-L 기반 매칭 비율을 산정한다. 이 지표는 다중 산출물 출력에서 산출물 수의 차이와 의도 분포의 차이를 동시에 반영한다.

\subsection{이미지 단계 평가}

이미지 단계 평가는 결정론적 평가를 보완한다. M1 렌더링 성공률은 산출물이 유효한 시각화로 렌더링되는지를 결정론적으로 판단한다. M5 CLIPScore는 OpenCLIP ViT-L/14 모델을 로컬에서 추론하여 시각화 이미지와 질의 텍스트 간의 의미적 유사도를 측정한다. A5 시각 리커트 척도는 Claude Sonnet 4.6 비전 API를 통해 완전성, 충실성, 배치의 세 차원에서 1점부터 5점까지의 평점을 100개 부집합에 대해 산정한다. 시제품 단계에서 활용하였던 \texttt{claude -p} 명령줄 도구는 사용량 제한으로 인해 2,800회의 배치 호출을 처리하지 못하므로, 본 연구는 Anthropic API의 배치 모드로 전환하여 활용한다.

\subsection{시제품 단계 평가 방식의 폐기}

시제품 단계에서 운영하였던 네 축 RocketEval 평가 방식은 본 연구에서 폐기한다. 이러한 결정의 근거는 두 가지이다. 첫째, Doc2Chart의 사람 정합성 $r=0.71$과 DiagramEval의 $r=0.43$은 이미 출판된 검증 결과이며, 우리 결정론적 1차 평가의 학계 정합성을 충분히 확보한다. 둘째, 자체 평가 설계의 정당화 — 특히 시제품 단계에서 도입하였던 교차 축 오염 방지 규칙 — 는 추가적인 정당화 부담을 발생시키므로, 학계 합의가 이미 형성된 두 외부 평가의 활용이 더 효율적이다.

\subsection{엄격 게이트 정의}

본 연구의 강 신호 (strict signal) 기준은 다음과 같이 정의된다. DocViz-Agent의 완전판 (B6)이 계열별 구조 지표 (차트 계열은 CHARTEVAL, 도식 계열은 DiagramEval 경로 F1), Evidence F1, Intent Coverage의 세 지표 모두에서 가장 강한 비교 대상 대비 $+0.020$ 이상의 차이를 보일 때 강 신호로 판정한다. 본 연구는 자체 합산 점수 (예: 가중치 합계)를 사용하지 않으며, 이는 가중치 정당화 부담을 회피하기 위한 의도적 결정이다.

\subsection{백본 모델}

본 연구는 네 개의 백본 모델을 채택하며, 각각이 서로 다른 등급과 제공사를 대표하도록 구성된다. 오픈 프론티어 백본인 Qwen3.5-397B-A17B-FP8은 본 연구의 시제품 단계에서 강 신호 기준을 만족한 것으로 검증되어 주요 측정 백본의 역할을 수행한다. 오픈 전문가 혼합 백본인 DeepSeek-V4-Flash는 두 번째 아키텍처 가족을 대표하여 결과의 아키텍처 의존성을 검증한다. 클로즈드 저비용 백본인 OpenAI GPT-5-mini는 비용 효율 측면에서, 클로즈드 프론티어 백본인 Anthropic Claude Opus 4.8은 최상위 모델 성능 측면에서 검증을 담당한다. 이러한 등급 분산은 네 사분면 — 오픈 대 클로즈드, 저비용 대 프론티어 — 을 모두 포괄함으로써 본 연구의 발견이 단일 모델군에 의존하지 않음을 입증한다.

난이도 필터링과 골드 추출에 사용되는 모델은 평가 풀과 분리된다. GPT-5 완전판과 Claude Opus 4.7이 다수결로 사용되며, 두 모델 모두 평가 풀에 포함되지 않음으로써 순환 평가의 위험을 차단한다.

\subsection{질의 생성 파이프라인}
\label{sec:query-gen}

질의 생성은 세 단계로 구성된 파이프라인을 통해 수행되며, 각 단계는 선행 연구에서 검증된 메커니즘을 차용한다. 모든 출처 벤치마크에 동일한 프롬프트 템플릿이 적용되며, 출처별 추론 표지만 슬롯에 삽입된다.

첫째, 압축 문서 표현 단계에서는 Loong의 자기 보고된 자료 생성 절차를 차용하여 각 문서를 핵심 사실 글머리 목록으로 LLM이 압축한다. 원문을 그대로 사용하는 대신 압축된 표현을 사용함으로써 후속 단계의 모델이 핵심 정보에 집중할 수 있도록 한다. 둘째, 과제별 프롬프트와 출력 유형 휴리스틱 단계에서는 추론 난이도 유형과 출력 구조 조합별로 25개의 프롬프트 템플릿을 준비하며, 각 템플릿은 한 차례의 학습 시연 예시를 포함한다. 출처 벤치마크의 표본 단위 추론 표지는 정박 근거로 명시되어 생성된 질의가 해당 추론 유형을 반드시 요구하도록 강제한다. 셋째, 자기 평가 관문 단계에서는 Text2Chart31의 메커니즘을 차용하여 동일 LLM이 생성된 질의를 다문서 필요성, 시각화 적합성, 사용자 의도 현실성의 세 가지 기준에서 평가하며, 세 기준을 모두 충족하는 경우에만 채택한다.

전체 파이프라인의 비용은 300개 질의에 대해 LLM 호출 900회 (단계당 1회씩) × GPT-4o-mini 단가 약 $\$0.001$로 약 $\$0.96$이며, Prolific 자연스러움 점검 30표본 약 $\$30$을 합산하여 총 약 $\$31$이다.

난이도 필터링은 GPT-5 완전판과 Claude Opus 4.7의 다수결로 수행된다. 두 모델이 모두 통과하는 질의는 너무 쉬운 것으로 간주되어 제거되며, 두 모델 모두 실패하는 질의 100개를 엄격 표본으로, 한 모델만 실패하는 질의 200개를 완화 표본으로 구성하여 총 300개의 다문서 묶음을 확보한다.

\subsection{골드 부집합 사람 검증}

300개 표본 중 90개의 부집합 (추론 난이도 유형별 15개, 도메인 상한 6 적용)을 Prolific에서 사람 검증한다. 검증 절차는 두 단계로 구성된다. 먼저 다중 LLM 합집합 추출 단계에서 GPT-5-mini와 Claude Opus 4.8이 동일 프롬프트로 독립적으로 증거 범위, 사실, 표, 그래프, 의도를 추출하며, 두 결과의 합집합을 취한 후 중복을 제거한다. 다음으로 Prolific에서 90개 표본 각각에 대해 세 명의 평가자가 두 가지 과제를 수행한다. 출처 정확성 과제에서는 각 사실이 인용된 원문 범위에 실제로 존재하는지를 이진 판정하며, 2/3 이상의 동의가 있을 때 해당 사실을 보존한다. 완전성 과제에서는 평가자가 자유 텍스트로 누락된 중요 사실을 추가하며, 추가된 사실은 네 번째 평가자가 재검증한 후 병합된다. 시제품 단계에서 운영하였던 과추출 점검 과제는 셀 수준 골드를 자체 구현하지 않는 본 연구의 설계에 따라 폐기된다.

\section{검증 (Validation)}
% =====================================================================

본 연구의 평가 정합성은 세 가지 방식으로 검증된다 (표~\ref{tab:a3}). 첫째, 30개 시각화에 대해 Prolific에서 사람 평가를 수집하여 본 연구의 1차 지표와의 스피어만 상관을 측정한다. 목표 기준은 DiagramEval 원논문에서 보고된 $r=0.43$의 범위에 해당하는 $r \geq 0.4$이다. 둘째, 역방향 질의응답을 통해 GPT-5-mini가 생성된 시각화만을 보고 원래 질의에 답한 정확도를 측정하며, B6가 가장 강한 비교 대상 대비 양의 방향의 격차를 보이는지 검증한다. 셋째, 외부 보류 평가에서 Text2Vis, Doc2Chart, SciDoc2DiagramBench의 전문가 모델 대비 $-7\%$ 포인트 이내의 격차를 보이는지 검증한다.

\section{논의 및 한계 (Discussion and Limitations)}
% =====================================================================

본 연구가 첫 일반화 파이프라인이라고 주장하는 까닭은 다문서 입력, 질의 기반 의도 추출, 다중 시각화 기본형 적용 범위라는 세 요건의 교집합을 다루는 과제 (QG-MDV)를 정형화한 첫 연구이기 때문이다. 선행 연구들은 각각 한 차원만을 다루었다. MMLongBench-Doc은 다문서 질의응답을 다루지만 시각화 출력이 없으며, Text2Vis는 시각화 출력을 다루지만 단일 문서와 단일 시각화 유형에 국한된다. Doc2Chart는 의도 기반 차트 생성을 다루지만 단일 문서와 차트 전용에 국한되며, DiagramEval은 도식 평가를 다루지만 다문서 입력이 아니다.

본 연구의 한계는 다음과 같다. 첫째, 도메인 범위가 의료, 금융, 법률, 학술, 뉴스, 시계열에 중심이 두어져 있어 안내서나 도서 등의 도메인은 포함되지 않는다. 이는 MMLongBench-Doc의 일곱 도메인 중 네 도메인만을 활용한 결과이다. 둘째, 본 연구는 실제 PDF 문서만을 사용하며 Wikipedia 기반 데이터를 의도적으로 배제하였다. HotpotQA, 2WikiMultihopQA, MuSiQue 등 Wikipedia 기반 다단계 질의응답 데이터는 본 연구의 과제 정의인 ``실세계 원문 자료''에 부합하지 않는다고 판단하였다. 셋째, 출력 도메인 특화 언어가 Chart.js와 Mermaid로 한정되어 TikZ나 기타 도식 형식은 지원되지 않는다. SciDoc2DiagramBench 보류 평가에서는 이러한 형식 불일치로 인해 이미지 단계 지표만을 적용한다. 넷째, 본 연구는 자체 정상화 계층의 도입을 의도적으로 회피하였다. 일부 개체 변이나 수치 단위 변동으로 인한 대칭적 잡음은 모든 비교 대상에 동일하게 적용되므로 순위에는 영향이 없으나, 절대 점수는 선행 연구의 측정값보다 약간 낮을 수 있다. 다섯째, 사람 검증의 범위가 의도적으로 제한되었다. 30개 자연스러움 점검, 90개 골드 부집합, 50개 시각화 교차 평가 점검만을 사람이 검증하며, 대규모 사람 평가는 선행 연구에서 검증된 사람 정합성을 인계받는 방식으로 대체된다.

% =====================================================================
\section{결론 (Conclusion)}
% =====================================================================

본 논문은 다문서 질의 기반 시각화 (QG-MDV) 과제를 정형화하고, 일곱 개의 학계 검증 벤치마크에서 300개 다문서 묶음을 추출하여 구성한 벤치마크와, 교차문서 반복 검색, 유형 인식 다중 시각화 생성, 출처 귀속 출력의 세 축으로 구성된 DocViz-Agent를 제안하였다. 평가 프레임워크는 차트 계열에 Doc2Chart의 주의 가중치 기반 귀속 지표를, 도식 계열에 DiagramEval의 그래프 정렬 지표를 결합한 결정론적 평가 방식을 채택하여 자체 정상화 계층의 도입을 회피한다. 다섯 단계로 분리된 실험 진행 계획은 시제품 단계에서 발견된 평가 결함 문제를 단계별 검증 기준으로 차단하며, 네 백본 모델에 걸친 측정을 통해 다문서 출처 귀속 격차가 백본과 파이프라인 종류에 무관하게 존재한다는 진단적 발견을 검증한다.

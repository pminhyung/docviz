\begin{abstract}
다수의 문서에 분산된 정보를 통합하여 사용자 질의에 부합하는 시각화 산출물을 생성하는 과제는 실세계 정보 처리 작업에서 핵심적이지만, 기존 연구는 단일 문서 단일 시각화 유형에 국한되어 왔다. 본 논문은 이러한 작업을 다문서 질의 기반 시각화 (Query-Grounded Multi-Document Visualization, QG-MDV)로 정형화하고, 학계에서 검증된 일곱 개의 다문서 벤치마크로부터 표본 단위 추론 유형 표지를 보존한 300개 다문서 묶음을 구축한다. 제안 방법 DocViz-Agent는 다섯 개의 축 — 교차문서 반복 검색 (Cross-doc Iterative Search, CIS), 전략적 증거 표현 (Strategic Evidence Format, SEF), 유형 인식 다중 시각화 생성 (Type-aware Multi-Viz Generation, TMG), 출처 귀속 출력 (Source-Attributed Output, SAO), 시각 사양 계약 (Visual Specification Contract, VSC) — 으로 구성된다. SEF는 dots.mocr (3B 다국어 문서 레이아웃 파싱 모델)의 결정론적 추출 결과를 본 연구의 결정론적 파이프라인이 직접 소비할 수 있는 구조적 표현으로 변환하며, VSC는 시각화 도메인 특화 언어 (Domain-Specific Language, DSL)의 형식적 계약, 위반 검증기 (validator), 일회성 보수 (repair) 루프로 구성된다. SEF와 VSC가 처리하는 실패 양상 — 형식 오류 DSL, 차원 불일치 차트, 끊어진 도식 엣지, 미지원 시각 표지, 산출물 간 증거 불일치 — 은 다문서 질의응답에 존재하지 않는 시각화 고유 (viz-exclusive) 양상이다. 평가는 DiagramEval의 렌더링-시각 언어 모델 추출 기반 그래프 정렬 지표를 차트와 도식 두 계열에 통합 적용한다. 네 개 백본에 걸친 교차 실험을 통해 다문서 출처 귀속 점수가 백본 종류와 파이프라인 종류에 무관하게 일관되게 낮음을 진단적 발견으로 제시한다.
\end{abstract}

\section{서론 (Introduction)}
% =====================================================================

대형 언어 모델 (Large Language Model, LLM) 기반 자동 시각화 생성에 관한 최근 연구들은 단일 표 혹은 단일 텍스트로부터 차트와 도식을 생성하는 능력을 빠르게 향상시켜 왔다 \cite{han2023chartllama,yang2024chartmimic}. 그러나 실제 정보 처리 작업의 다수는 단일 문서로부터의 변환이 아니라 여러 문서에 분산된 정보를 통합한 뒤 시각화하는 형태이다. 금융 분석가는 복수의 사업보고서로부터 부문별 매출 추이를 통합 시각화하며, 의학 연구자는 다수의 논문에서 약물 효과의 시간적 변화를 정리하고, 정책 분석가는 정부 보고서 간 정책 변화의 인과 흐름을 도식화한다. 이러한 작업은 정보 출처가 다중 문서이고, 사용자 의도가 자연어 질의로 표현되며, 출력 형식이 차트와 도식을 모두 포괄해야 한다는 점에서 기존 단일 문서 단일 유형 시각화 생성 연구가 다루지 못한 영역이다.

본 논문은 이러한 작업을 \textbf{다문서 질의 기반 시각화 (Query-Grounded Multi-Document Visualization, QG-MDV)}로 정형화한다. 본 과제는 자연어 질의 $Q$와 다문서 묶음 $\mathcal{D} = \{D_1, \dots, D_n\}$ ($n \geq 2$)이 주어질 때, 모든 시각적 주장이 $\mathcal{D}$의 어느 문서 청크에 근거되고 $Q$의 정보 요구를 만족하는 시각화 산출물 $V$를 생성하는 것을 목표로 한다. 출력은 결정론적 도메인 특화 언어 (Domain-Specific Language, DSL)인 Chart.js JSON 또는 Mermaid 마크다운으로 표현되며, 차트 계열 다섯 종과 도식 계열 다섯 종으로 구성된 열 가지 시각화 기본형으로 한정된다.

\textbf{시각화 생성의 고유 어려움.} 다문서 질의응답 (Multi-Document QA, MD-QA)과 비교했을 때, 다문서 질의 기반 시각화는 다음 다섯 가지 실패 양상을 추가로 다루어야 한다: (i) 형식 오류 DSL, (ii) 차원 불일치 차트 (예: 레이블 수 $\neq$ 데이터 점 수), (iii) 끊어진 도식 엣지 (참조되지 않는 노드 식별자), (iv) 미지원 시각 표지, (v) 산출물 간 증거 불일치 (한 산출물의 수치가 다른 산출물의 수치와 모순). 이러한 양상은 다문서 질의응답의 평가 양식에 존재하지 않는, 시각화 생성에 고유한 (viz-exclusive) 어려움이다. 본 연구는 이러한 양상을 체계적으로 처리하기 위한 시각 사양 계약 (VSC)을 제안한다.

\textbf{기여 (Contributions).} 본 연구의 기여는 다음 네 가지로 요약된다.

(C1) 일곱 개의 학계 검증 다문서 벤치마크 — Loong \cite{wang2024loong}, DocHop-QA \cite{xiaoaug2025dochop}, FinMMDocR \cite{2026finmmdocr}, VisDoMBench \cite{suri2025visdom}, MultiHop-RAG \cite{tang2024multihoprag}, FinAuditing \cite{wang2025finauditing}, TEMPO \cite{2026tempo} — 로부터 표본 단위 추론 유형 표지를 보존한 300개 다문서 묶음을 추출한 QG-MDV 벤치마크. 모든 원문은 실제 PDF 또는 구조화 문서이며 Wikipedia 발췌는 포함되지 않는다.

(C2) 다섯 축 — CIS, SEF, TMG, SAO, VSC — 으로 구성된 DocViz-Agent. SEF는 dots.mocr \cite{zheng2026dotsmocr}의 결정론적 레이아웃 + SVG 추출 결과를 시각 사양 생성에 최적화된 구조적 표현으로 변환하며, VSC는 시각 DSL의 형식 계약과 위반 검증기, 일회성 보수 루프로 구성된다. 시제품 측정에서 TMG 단독 절제 시 절대 점수 격차 $\Delta=-0.254$로 가장 컸으며, VSC와 SEF의 추가 절제 효과는 본 연구의 5단계 측정으로 검증한다.

(C3) DiagramEval \cite{liang2025diagrameval}의 그래프 정렬 지표를 차트와 도식 두 계열에 통합 적용하는 단일 결정론적 평가. 공식 코드가 공개된 DiagramEval만을 차용하여 자체 규칙 기반 정상화 계층을 회피한다. VSC 위반 비율 (예: M1 렌더링 실패, 차원 불일치, 끊어진 엣지)을 보조 결정론적 지표로 보고한다.

(C4) 네 개 백본 모델에 걸친 실험을 통해 다문서 출처 귀속 점수가 백본과 파이프라인 종류에 무관하게 일관되게 낮음을 보이며, 이를 과제 본질적 병목으로 제시한다.

\section{관련 연구 (Related Work)}
% =====================================================================

\subsection{차트 및 도식 생성}

ChartLlama \cite{han2023chartllama}, Text2Chart31 \cite{zadeh2024text2chart31}, ChartMimic \cite{yang2024chartmimic}은 단일 표 혹은 단일 텍스트로부터 차트를 생성하는 능력을 다룬다. SciDoc2Diagrammer-MAF \cite{mondal2024scidoc2diagrammer}는 단일 학술 논문으로부터 도식 생성을 다루지만 다문서 통합은 다루지 않는다. 본 연구는 입력이 단일 문서가 아닌 다문서 묶음이라는 점, 그리고 출력의 형식 계약을 명시적으로 강제한다는 점에서 이러한 선행 연구와 구분된다.

\subsection{다문서 질의응답과의 차이}

HotpotQA \cite{yang2018hotpotqa}, MMLongBench-Doc \cite{ma2024mmlongbench} 등 다문서 질의응답 연구는 다문서 추론과 출처 귀속을 다룬다. 본 연구는 이러한 연구로부터 문서 풀과 추론 유형 표지를 차용하되 출력 형식을 시각화로 재정의함으로써, 다문서 질의응답에 존재하지 않는 다섯 가지 시각화 고유 실패 양상 (\S 1)을 평가 대상으로 추가한다. CIS, SAO 두 축은 다문서 질의응답과 메커니즘을 공유하나, SEF, TMG, VSC 세 축은 시각화 생성 특유의 양상을 다룬다.

\subsection{시각화 평가}

DiagramEval \cite{liang2025diagrameval}은 도식을 렌더링한 후 시각 언어 모델로 노드와 엣지를 추출하여 그래프로 변환하고, 노드 정렬과 경로 정렬 지표로 평가하며 사람 평가와 피어슨 상관 $r=0.43$의 정합성을 보인다. 공식 코드가 저자 GitHub 저장소에 공개되어 있다. Doc2Chart \cite{jain2025doc2chart}는 교차 주의 가중치 기반 귀속 지표 CHARTEVAL을 제안하나 본 연구 작성 시점 기준 공식 평가 코드가 공개되지 않았으므로 채택하지 않는다. 본 연구는 DiagramEval의 렌더링-시각 언어 모델 추출 접근법을 차트와 도식 두 계열에 통합 적용한다.

\subsection{문서 레이아웃 파싱}

dots.mocr \cite{zheng2026dotsmocr}는 3B 파라미터의 다국어 문서 파싱 시각 언어 모델로, 페이지의 모든 레이아웃 요소 (제목, 본문, 표, 그림, 캡션 등)의 경계 상자와 의미 범주, 그리고 각 요소의 텍스트 (표는 HTML, 수식은 LaTeX, 나머지는 마크다운)를 단일 호출로 산출한다. 변형 모델 dots.mocr-svg는 차트와 그림을 SVG 코드로 직접 추출한다. 본 연구는 이러한 결정론적 추출 결과를 출발점으로 SEF (\S 4.2)를 구성한다. 본 연구는 dots.mocr 자체의 추출 성능을 측정하지 않으며, 그 출력을 시각화 생성 파이프라인의 결정론적 입력 표현으로 활용한다.

\section{QG-MDV 과제 정형화 (Task Formalization)}
% =====================================================================

\subsection{정의}

QG-MDV 과제의 입력은 자연어 질의 $Q$와 다문서 묶음 $\mathcal{D} = \{D_1, \dots, D_n\}$ ($n \geq 2$)이며, 출력은 시각화 산출물 집합 $V = \{V_1, \dots, V_k\}$ ($1 \leq k \leq 3$)이다. 각 $V_j$는 결정론적 DSL (Chart.js JSON 또는 Mermaid 마크다운)로 표현된다. $V$는 다음 네 조건을 모두 충족해야 한다: 모든 시각적 요소가 $\mathcal{D}$의 특정 문서 청크에 근거, $Q$의 정보 요구를 만족, 정보 구조에 적합한 시각화 유형 선택, 그리고 각 $V_j$가 형식 계약 (\S 4.5)을 충족.

\subsection{두 가지 직교 분류 축}

각 질의는 두 개의 독립적인 분류 축으로 표현된다. 추론 난이도 (challenge type) 축은 다섯 가지이다: 다단계 추론 (multi-hop), 산출물 계획 (artifact planning), 혼합 산출물 (mixed artifact), 방해 문서 다수 (distractor-heavy), 모순 해소 (contradiction). 출력 구조 (output type) 축도 다섯 가지이다: 수치형, 관계형, 시간형, 계층형, 비교형. 두 축은 독립적이다.

\subsection{시각화 기본형}

출력 DSL은 열 가지 기본형으로 한정된다. 차트 계열: \texttt{chartjs\_bar}, \texttt{chartjs\_line}, \texttt{chartjs\_grouped\_bar}, \texttt{chartjs\_pie}, \texttt{chartjs\_scatter}. 도식 계열: \texttt{mermaid\_flowchart}, \texttt{mermaid\_timeline}, \texttt{mermaid\_mindmap}, \texttt{mermaid\_sequenceDiagram}, \texttt{mermaid\_classDiagram}. 두 DSL은 모두 공개 표준이며 LLM이 사전 학습 단계에서 학습한 형식이다.

\section{DocViz-Agent 방법 (Method)}
% =====================================================================

DocViz-Agent는 다섯 개의 축으로 구성된다. 처리 순서는 다음과 같다: 원문 PDF가 dots.mocr 결정론적 전처리를 거쳐 SEF로 변환되고, CIS가 질의에 적합한 SEF 블록을 검색하며, TMG가 검색된 블록의 구조에 적합한 시각화 유형을 결정하고, 시각 사양 (visual spec)이 생성된 후 결정론적으로 DSL로 변환되며, VSC 위반 검증기가 형식 계약 충족을 확인하고 위반 시 일회성 보수가 적용되며, SAO 메타데이터가 각 시각 요소에 부착된다.

\subsection{데이터 입력 모델}
\label{sec:layered}

방법 절을 기술하기에 앞서 본 연구의 데이터 입력 형태를 정의한다. 출처별 원본 형태에 따라 전처리 절차가 다르다 (구체적 절차는 실험 진행 계획서 \S 3 참조). 정의 단계에서는 모든 출처가 두 산출물 — \textbf{청크화된 텍스트}와 \textbf{SEF}\,—\,을 공통으로 보유한다는 사실이 충족된다.

\textbf{청크화된 텍스트 (모든 비교 대상의 공통 substrate)}: 각 문서가 \texttt{bid} 식별자로 인덱싱된 블록 텍스트의 순서 있는 집합. PDF 출처는 dots.mocr이 산출하는 블록 단위로, 텍스트 출처는 출처가 제공하는 텍스트 단위 (Loong의 ModelScope 마크다운, MultiHop-RAG 뉴스 기사 단락 등)로 청크화된다. bid 명명 규칙은 출처별로 결정론적이며 \S\ref{sec:bid-scheme}에 정의된다. 이 산출물이 모든 비교 대상의 plain text 입력이자 B6의 텍스트 검색 substrate이다.

\textbf{SEF (B6 전용 enrichment)}: 청크화된 텍스트의 \emph{동일 bid를 키로} 부가되는 구조적 메타데이터 — 청구 단위, Picture 메타데이터, Table 파싱 결과, 교차 참조, 시각화 가능 색인. SEF는 청크화된 텍스트를 대체하지 않으며 \emph{위에 부가}된다.

\subsection{블록 식별자 (bid) 체계}
\label{sec:bid-scheme}

모든 청크와 SEF 블록은 동일한 식별자 체계로 인덱싱된다.

\begin{itemize}[leftmargin=*]
    \item PDF 출처 (FinMMDocR, VisDoMBench, DocHop-QA의 PDF 표본): \texttt{bid = \{doc\_id\}\#p\{page\}\_b\{order\}} — dots.mocr 페이지 + 리딩 순서 기반.
    \item 텍스트 출처 (Loong, MultiHop-RAG, DocHop-QA 텍스트 표본): \texttt{bid = \{doc\_id\}\#c\{order\}} — 출처 제공 청크 또는 단락 순서.
    \item 구조화 출처 (FinAuditing XBRL, TEMPO 시계열): \texttt{bid = \{doc\_id\}\#s\{section\}\_r\{row\}} — 섹션 + 항목 순서.
\end{itemize}

식별자가 청크와 SEF 양쪽에 통일되므로, SAO가 산출하는 \texttt{evidence\_id = \{bid\}\#\{cuid\}}는 청크 단위 텍스트 조회와 SEF 블록 단위 구조적 조회 모두에 결정론적으로 도달한다.

\subsection{Agent 도구 (B6 전용)}

B6 (DocViz-Agent)는 본 연구의 harness가 제공하는 도구를 통해 청크와 SEF에 접근한다. 도구의 외부 명세는 다음과 같다 (내부 구현은 본 논문의 범위 밖).

\begin{itemize}[leftmargin=*]
    \item \textbf{문서 검색 도구}: 질의로부터 후보 bid를 반환.
    \item \textbf{청크 텍스트 조회 도구}: bid로 청크 텍스트 반환.
    \item \textbf{SEF 블록 조회 도구}: bid로 SEF 블록 메타데이터 반환.
    \item \textbf{문서 개요 조회 도구}: 문서 메타와 시각화 가능 색인 반환.
    \item \textbf{교차 참조 조회 도구}: bid로 연결된 다른 bid 반환.
\end{itemize}

비교 대상 (B1-B5, B7)은 도구를 사용하지 않으며 청크 텍스트를 리딩 순서로 연결한 plain text 입력만 받는다.

\subsection{교차문서 반복 검색 (Cross-doc Iterative Search, CIS)}

CIS는 질의 $Q$로부터 시작하여 문서 검색 도구로 후보 bid를 얻고, 각 후보의 텍스트와 SEF 메타데이터를 조회하며, 교차 참조 도구로 인접 블록 (그림이 참조하는 본문, 본문이 참조하는 표 등)을 추가 탐색한다. 충분성 (sufficiency) 자체 평가를 통과할 때까지 반복한다. 단일 시도 검색이 아닌 반복 검색을 채택함으로써 가교 개체 (bridge entity)를 따라가는 다문서 통합이 가능하다.

\subsection{전략적 증거 표현 (Strategic Evidence Format, SEF)}
\label{sec:sef}

\textbf{원리.} SEF는 청크화된 텍스트 위에 부가되는 결정론적 enrichment이다. 청크화된 텍스트는 모든 비교 대상이 공유하는 기본 substrate이며, SEF는 그 substrate 위에 시각 사양 생성에 최적화된 메타데이터를 동일 bid를 키로 부가한다: \textbf{(a) 청구 단위 (claim\_units)} — 텍스트 블록 내 수치 주장 분해. \textbf{(b) 그림 메타데이터} — PDF 출처의 Picture 블록에 한해 dots.mocr-svg 출력 SVG 코드 + 시각 유형 + 추출된 데이터 표. \textbf{(c) 표 파싱 결과} — Table 블록의 HTML을 행렬로 파싱. \textbf{(d) 교차 참조 (cross\_refs)}. \textbf{(e) 시각화 가능 색인 (viz\_affordance\_index)} — 출력 구조 유형별 후보 bid 목록.

\textbf{B6 전용성과 공정성.} SEF는 B6만 접근한다. 비교 대상 (B1-B5, B7)은 청크 텍스트를 리딩 순서로 연결한 plain text 입력을 받는다. 두 입력의 텍스트 내용은 동일하며 정보 원천 (원문 PDF 또는 출처 제공 텍스트)도 동일하다. SEF는 본 연구의 방법 기여이며, ``비교 대상이 SEF 메타데이터를 활용하지 못하는 것''은 비교 대상의 method 한계이지 불공정이 아니다 (\S\ref{sec:fairness} 참고).

\textbf{생성 비용.} SEF 생성은 LLM 호출 없이 청크 텍스트 + 규칙 기반 변환만으로 수행된다. PDF 출처의 그림 메타데이터에 한해 dots.mocr-svg (3B 모델, 로컬 추론, API 비용 없음)가 사용된다. 변환 규칙은 실험 진행 계획서 \S 3에 명시된다.

\subsection{유형 인식 다중 시각화 생성 (Type-aware Multi-Viz Generation, TMG)}

TMG는 CIS가 검색한 SEF 블록과 질의 $Q$를 입력으로 받아 다음을 결정한다: (i) 시각화 산출물의 수 ($k=1, 2, 3$), (ii) 각 산출물의 viz\_type (열 가지 기본형 중), (iii) 각 산출물에 매핑되는 SEF 블록 분할. 약한 사전 매핑 (수치형 → 차트, 관계형 → 도식 등)이 안내로 제공되나 강제 라우터는 아니다. 시제품 측정에서 TMG 단독 절제 시 절대 점수 격차가 $\Delta=-0.254$로 가장 컸으며, 이는 다문서 시각화의 본질적 어려움이 정보 추출 자체가 아닌 정보 구조에 적합한 시각화 형식 선택에 있음을 시사한다.

\subsection{출처 귀속 출력 (Source-Attributed Output, SAO)}

SAO는 생성된 시각 사양의 각 시각적 요소 (노드, 엣지, 데이터 점)에 SEF 블록 식별자와 청구 단위 식별자를 메타데이터로 부착한다. 형식은 \texttt{\{doc\_id\}\#\{bid\}\#\{cuid\}}로 통일된다. SAO 메타데이터는 VSC 위반 검증기 (\S 4.5)의 입력으로도 사용된다 (시각 요소가 참조하는 SEF 식별자가 실제로 SEF에 존재하는지 확인).

\subsection{시각 사양 계약 (Visual Specification Contract, VSC)}
\label{sec:vsc}

VSC는 세 개의 결정론적 구성 요소이다.

\textbf{(a) 정형 시각 사양 (Canonical Visual Spec).} TMG가 자유 형식 DSL을 직접 생성하는 대신, 우선 정형 사양을 생성한다. 차트의 경우 사양은 viz\_type, 축 정의, 시리즈 정의, 각 데이터 점의 (시리즈, 범주, 값, 단위, 출처 SEF 식별자)를 포함한다. 도식의 경우 사양은 viz\_type, 노드 집합 (각각 식별자와 라벨), 엣지 집합 (각각 출발 노드, 도착 노드, 관계 라벨, 출처 SEF 식별자)을 포함한다. 정형 사양은 부록에 JSON 스키마로 명세된다.

\textbf{(b) 결정론적 사양 → DSL 변환.} 정형 사양으로부터 Chart.js JSON 또는 Mermaid 마크다운으로의 변환은 LLM 호출 없이 규칙 기반으로 수행된다. 이로써 ``사양은 올바르나 DSL 변환에서 형식 오류 발생''의 양상이 차단된다.

\textbf{(c) 위반 검증기 (Validator) + 일회성 보수 루프.} 검증기는 다음 양상을 결정론적으로 검사한다: (i) DSL이 렌더링 가능한지 (M1 렌더 성공), (ii) 차원 정합 (Chart.js의 \texttt{labels.length} = 각 \texttt{datasets[i].data.length}), (iii) 엣지 노드 참조 유효성 (Mermaid에서 모든 엣지의 양 끝 노드가 노드 집합에 존재), (iv) 시각 표지 지원 여부 (열 가지 기본형 한정 충족), (v) 출처 SEF 식별자 유효성 (모든 출처 참조가 SEF에 존재). 위반 발견 시 위반 유형과 위치를 명시한 보수 프롬프트가 TMG에게 한 차례 전달되며, 보수 실패 시 M1 = 0으로 계상된다.

VSC가 처리하는 다섯 양상은 모두 다문서 질의응답에 존재하지 않는 시각화 고유 양상이다. 이것이 본 연구가 ``QG-MDV는 MD-QA의 출력 형식 변경에 불과한 과제가 아니다''라는 주장을 뒷받침하는 경험적 근거이다 (\S 9 참고).

\section{평가 프레임워크 (Evaluation Framework)}
% =====================================================================

\subsection{설계 원칙}

본 연구의 평가는 자체 규칙 기반 정상화 계층을 회피한다. 시제품 단계에서 자체 정확 일치 셀 F1과 자체 정규식 기반 Mermaid 파서를 도입한 결과 모든 비교 대상의 점수가 97\% 영점에 수렴하는 바닥 상태가 관찰되었으며, 이는 자체 구현된 규칙 기반 평가가 다양한 출력 형식 변이를 일관되게 처리하지 못함을 시사하였다. 본 연구는 공식 코드가 공개된 DiagramEval만을 평가 차용하여 선행 연구의 사람 정합성 검증을 인계받는다.

VSC 위반 검증기 (\S 4.5)는 평가 프레임워크의 일부가 아니며 \emph{생성 파이프라인의 일부}이다. 즉 VSC는 B6 산출물의 품질을 결정론적으로 보장하기 위한 메커니즘이며, 모든 비교 대상의 산출물은 동일한 DiagramEval 평가를 받는다.

\subsection{통합 결정론적 평가}

DiagramEval 절차: 산출물 PNG 렌더링 → 시각 언어 모델이 시각 요소 추출 → 노드 정렬 F1 + 경로 정렬 F1 계산. 의미적 임계값 (sentence-transformer 코사인 유사도 0.75) 기반 노드 매칭. 원논문 사람 정합성 $r=0.43$ (CLIPScore 대비 약 4배).

\textbf{시각 언어 모델 선택.} 원논문은 Gemini-2.0-Flash-lite 사용. 본 연구는 두 후보 — Qwen3.5-397B의 시각 변형 (로컬, 비용 0) 및 GPT-5-mini 시각 (배치 API) — 을 30개 표본 사람 점검으로 비교한 후 단일 모델을 채택하며, 선택된 모델이 모든 단계에 일관 적용된다.

\subsection{보조 지표}

\textbf{Evidence F1.} B6는 SAO 메타데이터로 \texttt{evidence\_ids}를 명시적으로 생성하므로 집합 기반 F1을 계산한다. 비교 대상은 시각화 텍스트와 원문 청크 간 임베딩 코사인 유사도 0.75 이상을 매칭으로 간주하는 암묵적 매칭을 적용한다. 두 방식은 별도 열로 보고된다.

\textbf{Intent Coverage.} 헝가리안 매칭으로 산출물을 골드 의도에 매칭한 후 ROUGE-L 기반 매칭 비율 계산.

\textbf{VSC 위반 비율 (보조 결정론적 지표).} M1 렌더링 성공률, 차원 정합 비율, 엣지 노드 참조 유효 비율, 출처 참조 유효 비율. VSC가 처리하는 다섯 양상의 정량적 빈도이며, 시각화 고유 어려움의 존재를 보이는 일관성 있는 결정론적 지표이다.

\textbf{이미지 단계.} M5 CLIPScore (OpenCLIP ViT-L/14 로컬). A5 시각 리커트 (Claude Sonnet 4.6 비전, Anthropic 배치 API 100개 부집합).

\subsection{엄격 게이트}

B6가 노드 F1, 경로 F1, Evidence F1, Intent Coverage 네 지표 모두에서 가장 강한 비교 대상 대비 $+0.020$ 이상의 차이를 보일 때 강 신호로 판정한다. 가중치 합산 점수는 사용하지 않는다.

세 단계: 압축 문서 표현 (Loong 절차 차용), 과제별 프롬프트와 출력 유형 휴리스틱 (25개 템플릿), 자기 평가 관문 (Text2Chart31 메커니즘). \textbf{중요}: 질의 생성은 dots.mocr 표준 마크다운만을 입력으로 사용하며, SEF 전용 정보 (예: \texttt{safe\_to\_use\_numerics}, \texttt{cross\_refs})는 질의에 누출되지 않는다. 이로써 ``B6만 답할 수 있는 질의''가 생성되지 않음을 보장한다. 비용 약 0.96달러 + Prolific 자연스러움 점검 30표본 30달러.

난이도 필터링: GPT-5 완전판과 Claude Opus 4.7의 다수결. 두 모델 모두 통과 시 제거 (너무 쉬움), 두 모델 모두 실패하는 100개를 엄격 표본, 한 모델만 실패하는 200개를 완화 표본으로 구성하여 총 300개 확보.

\subsection{골드 부집합 사람 검증}

300개 중 90개 부집합 (추론 난이도 유형별 15, 도메인 상한 6). 다중 LLM 합집합 추출 (GPT-5-mini + Claude Opus 4.8 독립 + 합집합) → Prolific 세 평가자 × 90표본 출처 정확성 (이진, 2/3 동의 보존) + 완전성 (누락 사실 추가, 네 번째 평가자 재검증).

\subsection{비교 대상과 공정성}
\label{sec:fairness}

본 연구의 공정성 원칙은 다음 세 가지 구분에 기반한다. 첫째, 모든 비교 대상이 \emph{동일한 원문 PDF}에 접근한다 (정보 동등성). 둘째, 각 비교 대상은 \emph{자신의 방법이 원래 가정한 입력 형식}을 받는다 (방법 보존성). 셋째, 본 연구의 방법 기여인 SEF는 B6에만 전달되며, 이는 ``B6의 방법이 SEF를 활용한다''는 사실의 직접 귀결이지 추가적 이점이 아니다 (방법 기여의 정당성).

이 원칙에 따라 비교 대상은 Layer 1 블록 텍스트의 리딩 순서 연결 (plain text 마크다운)을 입력으로 받으며 — 이는 dots.mocr 출력에 추가 가공 없이 도출된다 — 각자의 원래 입력 형식 가정에 따라 처리한다 (예: B1 MatPlotAgent는 plain text 가정, B2 NVAGENT는 pseudo-table 가정, B3 CoDA는 텍스트 데이터셋 가정). B6는 Layer 2 SEF + 다섯 도구 (\S\ref{sec:layered})에 접근한다.

\section{논의 및 한계 (Discussion and Limitations)}
% =====================================================================

\textbf{MD-QA와의 구분.} CIS와 SAO 두 축은 다문서 질의응답과 메커니즘을 공유한다. 그러나 SEF, TMG, VSC 세 축은 다문서 질의응답에 존재하지 않는 양상을 다룬다. SEF는 시각 사양 생성에 최적화된 표현 (수치 정규화, SVG 추출, 시각화 가능 색인)을 다루며, 질의응답의 평문 증거 추출 표현과 구조가 다르다. TMG는 ``열 가지 시각화 기본형 중 어느 것이 정보 구조에 적합한가''라는 결정을 다루며, 질의응답에는 이러한 결정이 존재하지 않는다. VSC가 처리하는 다섯 양상 — 형식 오류 DSL, 차원 불일치, 끊어진 엣지, 미지원 표지, 출처 참조 무효 — 은 질의응답의 평문 답에서 발생할 수 없다. 표 \ref{tab:vsc}의 VSC 위반 비율은 이러한 양상이 실제로 빈번하게 발생함을 정량적으로 보이는 결정론적 증거이다.

\textbf{한계.} (i) 도메인 범위는 의료, 금융, 법률, 학술, 뉴스, 시계열에 중심. (ii) 실제 PDF만 사용 (Wikipedia 배제). (iii) 출력 DSL이 Chart.js와 Mermaid로 한정. SciDoc2DiagramBench 보류 평가는 이미지 단계 지표만 적용. (iv) 자체 정상화 계층 회피. (v) 사람 검증 범위 제한 (30 자연스러움, 90 골드, 50 시각화 교차). (vi) Doc2Chart CHARTEVAL 미사용 (공식 평가 코드 미공개). (vii) DiagramEval 시각 언어 모델은 Qwen3.5-397B-VL 또는 GPT-5-mini 비전으로 대체 (사람 정합성 별도 점검). (viii) dots.mocr 추출 실패율 (PyMuPDF 대체 비율)이 보고된다. (ix) VSC의 보수 루프가 한 차례로 제한되어 일부 산출물은 보수 실패 후 M1=0 처리된다.

% =====================================================================
\section{결론 (Conclusion)}
% =====================================================================

본 논문은 QG-MDV 과제를 정형화하고 일곱 출처 벤치마크에서 추출한 300 다문서 묶음을 제시한다. DocViz-Agent는 다섯 축 — CIS, SEF, TMG, SAO, VSC — 으로 구성되며, SEF는 dots.mocr의 결정론적 추출을 시각 사양 생성에 최적화된 표현으로 변환하고 VSC는 시각화 고유의 다섯 실패 양상을 결정론적으로 처리한다. 평가는 DiagramEval 통합 적용 + VSC 위반 비율 보조 지표. 네 백본 측정을 통해 다문서 출처 귀속 격차의 백본 무관 일관성을 진단적 발견으로 제시한다.
